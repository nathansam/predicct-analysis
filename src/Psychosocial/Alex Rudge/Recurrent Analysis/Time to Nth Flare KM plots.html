Introduction

Recurrent-event view of flare risk: instead of “time to first flare” (Survival/Soft-hard-flares.qmd), this shows time from study entry to the 1st, 2nd, 3rd, and 4th flare, overlaid on the same axes to show how the cumulative probability of having reached each flare count evolves over follow-up. Curves are plotted as cumulative incidence (1 - KM survival, so they rise from 0 rather than fall from 1 - hence “increasing”).

Done separately for patient-reported (soft) and objective (hard) flares, and separately for the Full Cohort, Crohn’s Disease, and Ulcerative Colitis/IBDU - 6 panels, each with 4 overlaid curves (24 curves total).

Definitions, matching the rest of this repo’s recurrent analysis:

  • Flare episode dates: soft = portal route (episodes_soft_portal) + Qflare route (qflare_episodes) + hard-flare-imputed route (imputed_soft), exactly as combined in Poisson Analysis - Time-varying covariates.qmd. Hard = eos_objective_episodes (first + further objective flares).
  • Time to the Nth flare = days from entry_date to that flare’s date, ranked chronologically per participant within each flare type.
  • Follow-up is censored at 730.5 days (2 years), the same cutoff used throughout this repo - a participant who hasn’t reached N flares by then is censored at 730.5, not at their last observed questionnaire (no reliable per-participant “true” end-of-follow-up date is available - see build_event_counts.R’s header on the unresolved withdrawal-date gap).

Requires survival and broom.

Nth-flare survival data builder

For each participant and each flare number 1..max_n, produces one row: time = days from entry to that flare (or the 730.5-day cutoff if they never reached it), event = 1 if they reached it within the cutoff, 0 otherwise.

Code 
build_nth_flare_data <- function(cohort, episode_dates, entry_dates, max_n = 4, cutoff_days = 730.5) {
  ranked_episodes <- episode_dates %>%
    dplyr::semi_join(cohort, by = "ParticipantNo") %>%
    dplyr::group_by(ParticipantNo) %>%
    dplyr::arrange(episode_date, .by_group = TRUE) %>%
    dplyr::mutate(flare_rank = dplyr::row_number()) %>%
    dplyr::ungroup() %>%
    dplyr::filter(flare_rank <= max_n)

  purrr::map_dfr(seq_len(max_n), function(n) {
    nth <- ranked_episodes %>%
      dplyr::filter(flare_rank == n) %>%
      dplyr::left_join(entry_dates, by = "ParticipantNo") %>%
      dplyr::transmute(ParticipantNo, event_time = as.numeric(as.Date(episode_date) - as.Date(entry_date)))

    cohort %>%
      dplyr::select(ParticipantNo) %>%
      dplyr::left_join(nth, by = "ParticipantNo") %>%
      dplyr::mutate(
        flare_number = factor(n, levels = seq_len(max_n)),
        reached_in_time = !is.na(event_time) & event_time >= 0 & event_time <= cutoff_days,
        time = dplyr::if_else(reached_in_time, event_time, cutoff_days),
        event = dplyr::if_else(reached_in_time, 1L, 0L)
      ) %>%
      dplyr::select(ParticipantNo, flare_number, time, event)
  })
}

Plot builder

Code 
plot_nth_flare_cuminc <- function(nth_flare_data, title) {
  fit <- survival::survfit(survival::Surv(time, event) ~ flare_number, data = nth_flare_data)
  broom::tidy(fit) %>%
    dplyr::mutate(
      flare_number = stringr::str_remove(strata, "flare_number="),
      cum_incidence = 1 - estimate,
      cum_incidence_low = 1 - conf.high,
      cum_incidence_high = 1 - conf.low
    ) %>%
    ggplot2::ggplot(ggplot2::aes(x = time, y = cum_incidence, colour = flare_number, fill = flare_number)) +
    ggplot2::geom_step(linewidth = 0.7) +
    ggplot2::geom_ribbon(ggplot2::aes(ymin = cum_incidence_low, ymax = cum_incidence_high), alpha = 0.12, colour = NA) +
    ggplot2::scale_colour_brewer(palette = "Set1", name = "Flare number") +
    ggplot2::scale_fill_brewer(palette = "Set1", guide = "none") +
    ggplot2::coord_cartesian(ylim = c(0, 1)) +
    ggplot2::labs(title = title, x = "Days since entry", y = "Cumulative incidence") +
    ggplot2::theme_minimal()
}
