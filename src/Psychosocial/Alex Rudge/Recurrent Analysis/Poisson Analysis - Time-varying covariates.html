Introduction

Recurrent-event analogue of Longitudinal analysis/{HADS,PHQ,PSQI,Exercise, Fatigue,Life Events}/’s extended Cox models with a time-dependent covariate. Those files treat each psychosocial measure as time-varying (last-observation-carried-forward across assessments, via survival::tmerge()/tdc()) but only model the first flare, via Surv(tstart, tstop, endpoint) ~ score_group + ... + frailty(SiteNo).

This file keeps the same time-varying-exposure idea but models all flare episodes (from build_event_counts.R), via person-period Poisson/negative binomial regression instead of Cox:

\[Y_{ij} \mid b_i, s_{k(i)} \sim \text{Poisson}(\mu_{ij}), \qquad \log(\mu_{ij}) = \log(t_{ij}) + \beta_0 + \boldsymbol\beta_1^\top \mathbf{x}_{ij} + \boldsymbol\beta_2^\top \mathbf{z}_i + b_i + s_{k(i)}\]

where \(Y_{ij}\) is the number of flares in participant \(i\)’s \(j\)-th interval (bounded by their assessment months and a 730.5-day/2-year cutoff, matching the cutoff used throughout this repo’s other flare definitions), \(t_{ij}\) is that interval’s length (an offset, not a covariate), \(\mathbf{x}_{ij}\) is the time-varying exposure category active during the interval, \(b_i\) is a per-participant random intercept (playing the same role frailty/cluster(ParticipantNo) plays in the Cox version - it’s what makes this valid for recurrent, correlated events rather than one independent row per person), and \(s_{k(i)}\) is the per-site random intercept used everywhere else in this repo. Six exposures are covered (HADS anxiety, HADS depression, PHQ somatisation, PSQI sleep disturbance, Exercise, Fatigue, Life Events), each broken down into Full Cohort/Crohn’s Disease/Ulcerative Colitis-IBDU x patient-reported/objective flare, matching Poisson Analysis.qmd’s structure.

Known simplifications, worth revisiting before treating this as final:

  • FC held fixed at baseline, not time-varying - matches every other model in this repo (Cox and static Poisson alike), not a deliberate choice specific to this file.
  • No withdrawal-date filtering - same known gap as build_event_counts.R.
  • Sex/age/Smoke/IMD/FC/SiteNo come from build_event_counts.R’s shared covariates object throughout, not from each exposure’s own data_cleaning.R (which computes its own copies) - kept deliberately consistent with the rest of this repo’s recurrent analysis rather than exposure-specific.
  • Flare episode dates are pulled directly from build_event_counts.R’s objects - any future change to that file’s endpoint definitions flows through here automatically.
  • PHQ/PSQI/Exercise’s data_cleaning.R write an RDS file to a shared people/Alex/... path as a side effect of being sourced (pre-existing behaviour of those scripts, not introduced here) - comment those lines out locally first if you don’t want that write to fire.
  • Model-fitting/reporting is done through small shared helper functions (fit_recurrent_tdc, run_cell) rather than every cell being written out fully independently (unlike Poisson Analysis.qmd’s explicit style) - a deliberate trade-off given the combinatorial size here (7 exposure scores x 2 flare types x 3 diagnosis groups = 42 cells).

Person-period interval builder

Builds one row per participant per interval between consecutive assessments of the time-varying exposure (last-observation-carried-forward for any missed assessment), censored at 730.5 days. Y = number of flares landing in that interval, t = interval length in days (the offset). Generic across exposures - works whether the assessment schedule is fixed (HADS/PHQ/PSQI/ Exercise/Life Events, months 0/12/24) or monthly (Fatigue).

Code 
build_person_period <- function(cohort, episode_dates, exposure_long, entry_dates, cutoff_days = 730.5) {
  exposure_locf <- exposure_long %>%
    dplyr::semi_join(cohort, by = "ParticipantNo") %>%
    # Guards against a zero-length interval (log(0) in the offset) if a
    # participant has a duplicate row for the same assessment month.
    dplyr::distinct(ParticipantNo, month, .keep_all = TRUE) %>%
    dplyr::arrange(ParticipantNo, month) %>%
    dplyr::group_by(ParticipantNo) %>%
    tidyr::fill(score_group, .direction = "down") %>%
    dplyr::ungroup() %>%
    dplyr::filter(!is.na(score_group)) %>%  # no assessment yet to carry forward
    dplyr::mutate(interval_start = month * 365 / 12) %>%
    dplyr::filter(interval_start < cutoff_days)

  # Next assessment (or the cutoff, for the last one) closes each interval -
  # the same "carried forward until superseded" logic tdc() implements,
  # built directly instead of via tmerge.
  person_period <- exposure_locf %>%
    dplyr::group_by(ParticipantNo) %>%
    dplyr::arrange(interval_start, .by_group = TRUE) %>%
    dplyr::mutate(interval_stop = dplyr::lead(interval_start, default = cutoff_days)) %>%
    dplyr::ungroup() %>%
    dplyr::left_join(entry_dates, by = "ParticipantNo") %>%
    dplyr::mutate(t = interval_stop - interval_start)

  # Count flares landing in each interval (fan-out join: one row per
  # participant-interval-episode combination, then collapse to a count).
  events_per_interval <- person_period %>%
    dplyr::select(ParticipantNo, interval_start, interval_stop, entry_date) %>%
    dplyr::left_join(episode_dates, by = "ParticipantNo") %>%
    dplyr::mutate(
      event_day = as.numeric(as.Date(episode_date) - as.Date(entry_date)),
      in_interval = !is.na(event_day) & event_day >= interval_start & event_day < interval_stop
    ) %>%
    dplyr::group_by(ParticipantNo, interval_start, interval_stop) %>%
    dplyr::summarise(Y = sum(in_interval), .groups = "drop")

  person_period %>%
    dplyr::left_join(events_per_interval, by = c("ParticipantNo", "interval_start", "interval_stop")) %>%
    dplyr::mutate(Y = tidyr::replace_na(Y, 0))
}

Model-fitting and reporting helpers

run_cell() fits one exposure/flare-type/diagnosis-group cell, prints the AIC comparison and tidied NB rate ratios (auto-printed as the chunk’s result), and appends the score_group rows to the global rate_ratios accumulator (used by the combined forest plot at the end) - one line per cell below rather than each of the 42 cells repeating this in full.

Code 
fit_recurrent_tdc <- function(data) {
  f <- Y ~ score_group + Sex + age_decade + Smoke + IMD + FC +
    (1 | ParticipantNo) + (1 | SiteNo) + offset(log(t))
  list(
    poisson = lme4::glmer(f, data = data, family = poisson, control = glmer_control),
    nb = lme4::glmer.nb(f, data = data, control = glmer_control)
  )
}

# A model "failed to converge" means lme4's own post-fit check flagged it
# (fit@optinfo$conv$lme4$messages non-NULL) - NOT the same as a singular fit
# (boundary (singular) fit), which is a valid degenerate solution (a
# variance component at zero), not a convergence failure.
model_converged <- function(fit) {
  is.null(fit@optinfo$conv$lme4$messages)
}

rate_ratios <- tibble::tibble()

run_cell <- function(pp, dx, exposure, outcome, diagnosis_label) {
  d <- if (dx == "Full") pp else dplyr::filter(pp, diagnosis2 == dx)
  fit <- fit_recurrent_tdc(d)
  poisson_ok <- model_converged(fit$poisson)
  nb_ok <- model_converged(fit$nb)

  cat("n =", nrow(d),
      "| Poisson AIC:", if (poisson_ok) round(AIC(fit$poisson), 1) else "NA (failed to converge)",
      "| NB AIC:", if (nb_ok) round(AIC(fit$nb), 1) else "NA (failed to converge)", "\n\n")

  # Prefers NB (this repo's usual choice); falls back to Poisson if NB
  # failed to converge but Poisson didn't; discards the term entirely if
  # NEITHER converged. model_fit tags which model actually produced the
  # reported rate ratio, so the combined forest plot can show it.
  if (nb_ok) {
    tidy <- fit$nb %>% broom.mixed::tidy(exponentiate = TRUE, conf.int = TRUE) %>% dplyr::mutate(model_fit = "NB")
  } else if (poisson_ok) {
    cat("NB failed to converge - falling back to Poisson for this cell.\n\n")
    tidy <- fit$poisson %>% broom.mixed::tidy(exponentiate = TRUE, conf.int = TRUE) %>% dplyr::mutate(model_fit = "Poisson")
  } else {
    cat("Both Poisson and NB failed to converge for this cell - rate ratio not reported.\n\n")
    return(invisible(NULL))
  }

  rate_ratios <<- dplyr::bind_rows(
    rate_ratios,
    tidy %>%
      dplyr::filter(stringr::str_starts(term, "score_group")) %>%
      dplyr::mutate(exposure = exposure, outcome = outcome, diagnosis = diagnosis_label)
  )
  tidy
}

## Introduction

Recurrent-event analogue of `Longitudinal analysis/{HADS,PHQ,PSQI,Exercise,
Fatigue,Life Events}/`'s extended Cox models with a time-dependent
covariate. Those files treat each psychosocial measure as time-varying
(last-observation-carried-forward across assessments, via
`survival::tmerge()`/`tdc()`) but only model the *first* flare, via
`Surv(tstart, tstop, endpoint) ~ score_group + ... + frailty(SiteNo)`.

This file keeps the same time-varying-exposure idea but models *all* flare
episodes (from `build_event_counts.R`), via person-period Poisson/negative
binomial regression instead of Cox:

$$Y_{ij} \mid b_i, s_{k(i)} \sim \text{Poisson}(\mu_{ij}), \qquad
\log(\mu_{ij}) = \log(t_{ij}) + \beta_0 + \boldsymbol\beta_1^\top \mathbf{x}_{ij}
+ \boldsymbol\beta_2^\top \mathbf{z}_i + b_i + s_{k(i)}$$

where $Y_{ij}$ is the number of flares in participant $i$'s $j$-th interval
(bounded by their assessment months and a 730.5-day/2-year cutoff, matching
the cutoff used throughout this repo's other flare definitions), $t_{ij}$ is
that interval's length (an offset, not a covariate), $\mathbf{x}_{ij}$ is the
time-varying exposure category active during the interval, $b_i$ is a
per-participant random intercept (playing the same role
`frailty`/`cluster(ParticipantNo)` plays in the Cox version - it's what
makes this valid for *recurrent*, correlated events rather than one
independent row per person), and $s_{k(i)}$ is the per-site random intercept
used everywhere else in this repo. Six exposures are covered (HADS anxiety,
HADS depression, PHQ somatisation, PSQI sleep disturbance, Exercise, Fatigue,
Life Events), each broken down into Full Cohort/Crohn's Disease/Ulcerative
Colitis-IBDU x patient-reported/objective flare, matching `Poisson
Analysis.qmd`'s structure.

**Known simplifications, worth revisiting before treating this as final:**

- **FC held fixed at baseline**, not time-varying - matches every other
  model in this repo (Cox and static Poisson alike), not a deliberate
  choice specific to this file.
- **No withdrawal-date filtering** - same known gap as `build_event_counts.R`.
- **Sex/age/Smoke/IMD/FC/SiteNo come from `build_event_counts.R`'s shared
  `covariates` object throughout**, not from each exposure's own
  `data_cleaning.R` (which computes its own copies) - kept deliberately
  consistent with the rest of this repo's recurrent analysis rather than
  exposure-specific.
- Flare episode dates are pulled directly from `build_event_counts.R`'s
  objects - any future change to that file's endpoint definitions flows
  through here automatically.
- **PHQ/PSQI/Exercise's `data_cleaning.R` write an RDS file** to a shared
  `people/Alex/...` path as a side effect of being sourced (pre-existing
  behaviour of those scripts, not introduced here) - comment those lines out
  locally first if you don't want that write to fire.
- Model-fitting/reporting is done through small shared helper functions
  (`fit_recurrent_tdc`, `run_cell`) rather than every cell being written out
  fully independently (unlike `Poisson Analysis.qmd`'s explicit style) -
  a deliberate trade-off given the combinatorial size here (7 exposure
  scores x 2 flare types x 3 diagnosis groups = 42 cells).

## Person-period interval builder

Builds one row per participant per interval between consecutive assessments
of the time-varying exposure (last-observation-carried-forward for any
missed assessment), censored at 730.5 days. `Y` = number of flares landing
in that interval, `t` = interval length in days (the offset). Generic across
exposures - works whether the assessment schedule is fixed (HADS/PHQ/PSQI/
Exercise/Life Events, months 0/12/24) or monthly (Fatigue).

```{r}
build_person_period <- function(cohort, episode_dates, exposure_long, entry_dates, cutoff_days = 730.5) {
  exposure_locf <- exposure_long %>%
    dplyr::semi_join(cohort, by = "ParticipantNo") %>%
    # Guards against a zero-length interval (log(0) in the offset) if a
    # participant has a duplicate row for the same assessment month.
    dplyr::distinct(ParticipantNo, month, .keep_all = TRUE) %>%
    dplyr::arrange(ParticipantNo, month) %>%
    dplyr::group_by(ParticipantNo) %>%
    tidyr::fill(score_group, .direction = "down") %>%
    dplyr::ungroup() %>%
    dplyr::filter(!is.na(score_group)) %>%  # no assessment yet to carry forward
    dplyr::mutate(interval_start = month * 365 / 12) %>%
    dplyr::filter(interval_start < cutoff_days)

  # Next assessment (or the cutoff, for the last one) closes each interval -
  # the same "carried forward until superseded" logic tdc() implements,
  # built directly instead of via tmerge.
  person_period <- exposure_locf %>%
    dplyr::group_by(ParticipantNo) %>%
    dplyr::arrange(interval_start, .by_group = TRUE) %>%
    dplyr::mutate(interval_stop = dplyr::lead(interval_start, default = cutoff_days)) %>%
    dplyr::ungroup() %>%
    dplyr::left_join(entry_dates, by = "ParticipantNo") %>%
    dplyr::mutate(t = interval_stop - interval_start)

  # Count flares landing in each interval (fan-out join: one row per
  # participant-interval-episode combination, then collapse to a count).
  events_per_interval <- person_period %>%
    dplyr::select(ParticipantNo, interval_start, interval_stop, entry_date) %>%
    dplyr::left_join(episode_dates, by = "ParticipantNo") %>%
    dplyr::mutate(
      event_day = as.numeric(as.Date(episode_date) - as.Date(entry_date)),
      in_interval = !is.na(event_day) & event_day >= interval_start & event_day < interval_stop
    ) %>%
    dplyr::group_by(ParticipantNo, interval_start, interval_stop) %>%
    dplyr::summarise(Y = sum(in_interval), .groups = "drop")

  person_period %>%
    dplyr::left_join(events_per_interval, by = c("ParticipantNo", "interval_start", "interval_stop")) %>%
    dplyr::mutate(Y = tidyr::replace_na(Y, 0))
}
```

## Model-fitting and reporting helpers

`run_cell()` fits one exposure/flare-type/diagnosis-group cell, prints the
AIC comparison and tidied NB rate ratios (auto-printed as the chunk's
result), and appends the `score_group` rows to the global `rate_ratios`
accumulator (used by the combined forest plot at the end) - one line per
cell below rather than each of the 42 cells repeating this in full.

```{r}
fit_recurrent_tdc <- function(data) {
  f <- Y ~ score_group + Sex + age_decade + Smoke + IMD + FC +
    (1 | ParticipantNo) + (1 | SiteNo) + offset(log(t))
  list(
    poisson = lme4::glmer(f, data = data, family = poisson, control = glmer_control),
    nb = lme4::glmer.nb(f, data = data, control = glmer_control)
  )
}

# A model "failed to converge" means lme4's own post-fit check flagged it
# (fit@optinfo$conv$lme4$messages non-NULL) - NOT the same as a singular fit
# (boundary (singular) fit), which is a valid degenerate solution (a
# variance component at zero), not a convergence failure.
model_converged <- function(fit) {
  is.null(fit@optinfo$conv$lme4$messages)
}

rate_ratios <- tibble::tibble()

run_cell <- function(pp, dx, exposure, outcome, diagnosis_label) {
  d <- if (dx == "Full") pp else dplyr::filter(pp, diagnosis2 == dx)
  fit <- fit_recurrent_tdc(d)
  poisson_ok <- model_converged(fit$poisson)
  nb_ok <- model_converged(fit$nb)

  cat("n =", nrow(d),
      "| Poisson AIC:", if (poisson_ok) round(AIC(fit$poisson), 1) else "NA (failed to converge)",
      "| NB AIC:", if (nb_ok) round(AIC(fit$nb), 1) else "NA (failed to converge)", "\n\n")

  # Prefers NB (this repo's usual choice); falls back to Poisson if NB
  # failed to converge but Poisson didn't; discards the term entirely if
  # NEITHER converged. model_fit tags which model actually produced the
  # reported rate ratio, so the combined forest plot can show it.
  if (nb_ok) {
    tidy <- fit$nb %>% broom.mixed::tidy(exponentiate = TRUE, conf.int = TRUE) %>% dplyr::mutate(model_fit = "NB")
  } else if (poisson_ok) {
    cat("NB failed to converge - falling back to Poisson for this cell.\n\n")
    tidy <- fit$poisson %>% broom.mixed::tidy(exponentiate = TRUE, conf.int = TRUE) %>% dplyr::mutate(model_fit = "Poisson")
  } else {
    cat("Both Poisson and NB failed to converge for this cell - rate ratio not reported.\n\n")
    return(invisible(NULL))
  }

  rate_ratios <<- dplyr::bind_rows(
    rate_ratios,
    tidy %>%
      dplyr::filter(stringr::str_starts(term, "score_group")) %>%
      dplyr::mutate(exposure = exposure, outcome = outcome, diagnosis = diagnosis_label)
  )
  tidy
}
```
