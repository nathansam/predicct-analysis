Introduction

Recurrent-event (Poisson/NB) analogue of Sensitivity analysis/{HADS,PHQ, PSQI,Exercise,Fatigue,Life Events}.qmd’s Cox sensitivity models, the same way Poisson Analysis - Time-varying covariates.qmd is the recurrent analogue of Longitudinal analysis/’s primary Cox models. Structure and person-period machinery are identical to that file (see it for the mathematical specification) - this file only adds three covariates found in the reference Cox sensitivity formula (e.g. Sensitivity analysis/PSQI.qmd, cox_soft/cox_hard/cox_soft_uc/etc.):

Surv(time, DiseaseFlareYN) ~ <exposure> + IMD + Sex + age_decade + FC +
  Smoke + flare_group + OverallControl + control_8 + frailty(SiteNo)
  • flare_group - patient-reported flare in the previous year (“No Flares” vs “1 or More Flares”), from IBD.xlsx’s FlaresInPastYear.
  • OverallControl - IBD-Control-VAS (the single visual-analogue-scale item of the IBD-Control questionnaire).
  • control_8 - IBD-Control-8 (the 8-item summed score of the same questionnaire).

Both control scores come from IBD_C.RDS.

Two things in the reference sensitivity analysis this file does NOT replicate:

  • Multiple imputation (mice). The reference reports both a complete-case model and a MICE-pooled model (e.g. cox_results_psqi_cc vs cox_results_psqi_mice, m = 20 imputations). mice::pool() doesn’t have solid native support for glmer/glmer.nb objects the way it does for coxph, and an untested MI-pooling path isn’t something to guess at. This file is complete-case only - rows with a missing flare_group/OverallControl/control_8 are silently dropped by glmer’s default na.action, same as any other model here.
  • Per-cell spline exploration. The reference tests ns(OverallControl, df = 2)/ns(age_decade, df = 2) via likelihood-ratio tests in some cells. This file uses linear terms throughout, matching how FC/age_decade are already treated everywhere else in this repo’s Poisson models.

Everything else - the person-period construction, the six exposures, the Full Cohort/CD/UC x soft/hard breakdown, FC held fixed at baseline, no withdrawal-date filtering - carries over unchanged from Poisson Analysis - Time-varying covariates.qmd.

Person-period interval builder

Unchanged from Poisson Analysis - Time-varying covariates.qmd.

Code 
build_person_period <- function(cohort, episode_dates, exposure_long, entry_dates, cutoff_days = 730.5) {
  exposure_locf <- exposure_long %>%
    dplyr::semi_join(cohort, by = "ParticipantNo") %>%
    # Guards against a zero-length interval (log(0) in the offset) if a
    # participant has a duplicate row for the same assessment month.
    dplyr::distinct(ParticipantNo, month, .keep_all = TRUE) %>%
    dplyr::arrange(ParticipantNo, month) %>%
    dplyr::group_by(ParticipantNo) %>%
    tidyr::fill(score_group, .direction = "down") %>%
    dplyr::ungroup() %>%
    dplyr::filter(!is.na(score_group)) %>%  # no assessment yet to carry forward
    dplyr::mutate(interval_start = month * 365 / 12) %>%
    dplyr::filter(interval_start < cutoff_days)

  # Next assessment (or the cutoff, for the last one) closes each interval -
  # the same "carried forward until superseded" logic tdc() implements,
  # built directly instead of via tmerge.
  person_period <- exposure_locf %>%
    dplyr::group_by(ParticipantNo) %>%
    dplyr::arrange(interval_start, .by_group = TRUE) %>%
    dplyr::mutate(interval_stop = dplyr::lead(interval_start, default = cutoff_days)) %>%
    dplyr::ungroup() %>%
    dplyr::left_join(entry_dates, by = "ParticipantNo") %>%
    dplyr::mutate(t = interval_stop - interval_start)

  # Count flares landing in each interval (fan-out join: one row per
  # participant-interval-episode combination, then collapse to a count).
  events_per_interval <- person_period %>%
    dplyr::select(ParticipantNo, interval_start, interval_stop, entry_date) %>%
    dplyr::left_join(episode_dates, by = "ParticipantNo") %>%
    dplyr::mutate(
      event_day = as.numeric(as.Date(episode_date) - as.Date(entry_date)),
      in_interval = !is.na(event_day) & event_day >= interval_start & event_day < interval_stop
    ) %>%
    dplyr::group_by(ParticipantNo, interval_start, interval_stop) %>%
    dplyr::summarise(Y = sum(in_interval), .groups = "drop")

  person_period %>%
    dplyr::left_join(events_per_interval, by = c("ParticipantNo", "interval_start", "interval_stop")) %>%
    dplyr::mutate(Y = tidyr::replace_na(Y, 0))
}

Model-fitting and reporting helpers

Only change from the primary file: fit_recurrent_tdc()’s formula adds flare_group + OverallControl + control_8.

Code 
fit_recurrent_tdc <- function(data) {
  f <- Y ~ score_group + Sex + age_decade + Smoke + IMD + FC +
    flare_group + OverallControl + control_8 +
    (1 | ParticipantNo) + (1 | SiteNo) + offset(log(t))
  list(
    poisson = lme4::glmer(f, data = data, family = poisson, control = glmer_control),
    nb = lme4::glmer.nb(f, data = data, control = glmer_control)
  )
}

rate_ratios <- tibble::tibble()

run_cell <- function(pp, dx, exposure, outcome, diagnosis_label) {
  d <- if (dx == "Full") pp else dplyr::filter(pp, diagnosis2 == dx)
  fit <- fit_recurrent_tdc(d)
  cat("n =", nrow(d), "| Poisson AIC:", round(AIC(fit$poisson), 1),
      "| NB AIC:", round(AIC(fit$nb), 1), "\n\n")
  tidy <- fit$nb %>% broom.mixed::tidy(exponentiate = TRUE, conf.int = TRUE)
  rate_ratios <<- dplyr::bind_rows(
    rate_ratios,
    tidy %>%
      dplyr::filter(stringr::str_starts(term, "score_group")) %>%
      dplyr::mutate(exposure = exposure, outcome = outcome, diagnosis = diagnosis_label)
  )
  tidy
}

## Introduction

Recurrent-event (Poisson/NB) analogue of `Sensitivity analysis/{HADS,PHQ,
PSQI,Exercise,Fatigue,Life Events}.qmd`'s Cox sensitivity models, the same
way `Poisson Analysis - Time-varying covariates.qmd` is the recurrent
analogue of `Longitudinal analysis/`'s primary Cox models. Structure and
person-period machinery are identical to that file (see it for the
mathematical specification) - this file only adds three covariates found in
the reference Cox sensitivity formula (e.g. `Sensitivity analysis/PSQI.qmd`,
`cox_soft`/`cox_hard`/`cox_soft_uc`/etc.):

```
Surv(time, DiseaseFlareYN) ~ <exposure> + IMD + Sex + age_decade + FC +
  Smoke + flare_group + OverallControl + control_8 + frailty(SiteNo)
```

- **`flare_group`** - patient-reported flare in the previous year
  ("No Flares" vs "1 or More Flares"), from `IBD.xlsx`'s `FlaresInPastYear`.
- **`OverallControl`** - IBD-Control-VAS (the single visual-analogue-scale
  item of the IBD-Control questionnaire).
- **`control_8`** - IBD-Control-8 (the 8-item summed score of the same
  questionnaire).

Both control scores come from `IBD_C.RDS`.

**Two things in the reference sensitivity analysis this file does NOT
replicate:**

- **Multiple imputation (`mice`).** The reference reports both a
  complete-case model and a MICE-pooled model (e.g.
  `cox_results_psqi_cc` vs `cox_results_psqi_mice`, `m = 20` imputations).
  `mice::pool()` doesn't have solid native support for `glmer`/`glmer.nb`
  objects the way it does for `coxph`, and an untested MI-pooling path
  isn't something to guess at. **This file is complete-case only** - rows
  with a missing `flare_group`/`OverallControl`/`control_8` are silently
  dropped by `glmer`'s default `na.action`, same as any other model here.
- **Per-cell spline exploration.** The reference tests `ns(OverallControl,
  df = 2)`/`ns(age_decade, df = 2)` via likelihood-ratio tests in some
  cells. This file uses linear terms throughout, matching how FC/age_decade
  are already treated everywhere else in this repo's Poisson models.

Everything else - the person-period construction, the six exposures, the
Full Cohort/CD/UC x soft/hard breakdown, FC held fixed at baseline, no
withdrawal-date filtering - carries over unchanged from
`Poisson Analysis - Time-varying covariates.qmd`.

## Person-period interval builder

Unchanged from `Poisson Analysis - Time-varying covariates.qmd`.

```{r}
build_person_period <- function(cohort, episode_dates, exposure_long, entry_dates, cutoff_days = 730.5) {
  exposure_locf <- exposure_long %>%
    dplyr::semi_join(cohort, by = "ParticipantNo") %>%
    # Guards against a zero-length interval (log(0) in the offset) if a
    # participant has a duplicate row for the same assessment month.
    dplyr::distinct(ParticipantNo, month, .keep_all = TRUE) %>%
    dplyr::arrange(ParticipantNo, month) %>%
    dplyr::group_by(ParticipantNo) %>%
    tidyr::fill(score_group, .direction = "down") %>%
    dplyr::ungroup() %>%
    dplyr::filter(!is.na(score_group)) %>%  # no assessment yet to carry forward
    dplyr::mutate(interval_start = month * 365 / 12) %>%
    dplyr::filter(interval_start < cutoff_days)

  # Next assessment (or the cutoff, for the last one) closes each interval -
  # the same "carried forward until superseded" logic tdc() implements,
  # built directly instead of via tmerge.
  person_period <- exposure_locf %>%
    dplyr::group_by(ParticipantNo) %>%
    dplyr::arrange(interval_start, .by_group = TRUE) %>%
    dplyr::mutate(interval_stop = dplyr::lead(interval_start, default = cutoff_days)) %>%
    dplyr::ungroup() %>%
    dplyr::left_join(entry_dates, by = "ParticipantNo") %>%
    dplyr::mutate(t = interval_stop - interval_start)

  # Count flares landing in each interval (fan-out join: one row per
  # participant-interval-episode combination, then collapse to a count).
  events_per_interval <- person_period %>%
    dplyr::select(ParticipantNo, interval_start, interval_stop, entry_date) %>%
    dplyr::left_join(episode_dates, by = "ParticipantNo") %>%
    dplyr::mutate(
      event_day = as.numeric(as.Date(episode_date) - as.Date(entry_date)),
      in_interval = !is.na(event_day) & event_day >= interval_start & event_day < interval_stop
    ) %>%
    dplyr::group_by(ParticipantNo, interval_start, interval_stop) %>%
    dplyr::summarise(Y = sum(in_interval), .groups = "drop")

  person_period %>%
    dplyr::left_join(events_per_interval, by = c("ParticipantNo", "interval_start", "interval_stop")) %>%
    dplyr::mutate(Y = tidyr::replace_na(Y, 0))
}
```

```{r}
fit_recurrent_tdc <- function(data) {
  f <- Y ~ score_group + Sex + age_decade + Smoke + IMD + FC +
    flare_group + OverallControl + control_8 +
    (1 | ParticipantNo) + (1 | SiteNo) + offset(log(t))
  list(
    poisson = lme4::glmer(f, data = data, family = poisson, control = glmer_control),
    nb = lme4::glmer.nb(f, data = data, control = glmer_control)
  )
}

rate_ratios <- tibble::tibble()

run_cell <- function(pp, dx, exposure, outcome, diagnosis_label) {
  d <- if (dx == "Full") pp else dplyr::filter(pp, diagnosis2 == dx)
  fit <- fit_recurrent_tdc(d)
  cat("n =", nrow(d), "| Poisson AIC:", round(AIC(fit$poisson), 1),
      "| NB AIC:", round(AIC(fit$nb), 1), "\n\n")
  tidy <- fit$nb %>% broom.mixed::tidy(exponentiate = TRUE, conf.int = TRUE)
  rate_ratios <<- dplyr::bind_rows(
    rate_ratios,
    tidy %>%
      dplyr::filter(stringr::str_starts(term, "score_group")) %>%
      dplyr::mutate(exposure = exposure, outcome = outcome, diagnosis = diagnosis_label)
  )
  tidy
}
```

## Combined rate ratio forest plot

All seven exposure scores together, split by flare type and diagnosis group,
adjusted for `flare_group`/`OverallControl`/`control_8` in addition to the
base covariates. Uses the NB fit throughout.

```{r}
#| fig-width: 10
#| fig-height: 12
rate_ratios %>%
  dplyr::mutate(
    label = paste0(exposure, ": ", term),
    significant = conf.low > 1 | conf.high < 1,
    diagnosis = factor(diagnosis, levels = c("Full Cohort", "Crohn's Disease", "Ulcerative Colitis/IBDU"))
  ) %>%
  ggplot2::ggplot(ggplot2::aes(x = estimate, y = label, colour = significant)) +
  ggplot2::geom_vline(xintercept = 1, linetype = "dashed", colour = "grey50") +
  ggplot2::geom_pointrange(ggplot2::aes(xmin = conf.low, xmax = conf.high)) +
  ggplot2::scale_x_log10() +
  ggplot2::scale_colour_manual(values = c(`TRUE` = "#0F8B8D", `FALSE` = "grey60"), guide = "none") +
  ggplot2::facet_grid(diagnosis ~ outcome) +
  ggplot2::labs(x = "Adjusted rate ratio (95% CI, log scale)", y = NULL) +
  ggplot2::theme_minimal()
```
