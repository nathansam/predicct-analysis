Introduction

Poisson/negative-binomial equivalent of the Cox models in Primary Analysis/: We thi models the number of flare events during follow-up (recurrent events) (see Events per individual.R and build_event_counts.R for how those counts and the endpoint definitions are constructed).

Six exposures are tested, as in thecorresponding Primary Analysis file (HADS, PHQ, PSQI, Exercise, Fatigue, Life Events).

Every exposure is broken down into Full Cohort/Crohn’s Disease/Ulcerative Colitis-IBDU, each further split by patient-reported (soft) vs objective (hard) flare (the same structure Primary Analysis). Each of those cells fits an unadjusted model (exposure + (1 | SiteNo)) and an adjusted one (+ Sex + age_decade + Smoke + IMD + FC), as both Poisson and negative binomial, written out explicitly per cell rather than looped. A combined forest plot across all six exposures follows the individual sections.

Requires the lme4 and broom.mixed packages.

# A model "failed to converge" means lme4's own post-fit check flagged it
# (fit@optinfo$conv$lme4$messages non-NULL) - NOT the same as a singular fit
# (boundary (singular) fit), which is a valid degenerate solution (a
# variance component at zero), not a convergence failure.
model_converged <- function(fit) {
  is.null(fit@optinfo$conv$lme4$messages)
}

aic_or_na <- function(fit) {
  if (model_converged(fit)) round(AIC(fit), 1) else "NA (failed to converge)"
}

# Swapped in for every broom.mixed::tidy(<nb model>, conf.int = TRUE,
# exponentiate = TRUE) call below. Prefers the NB rate ratio (this repo's
# usual choice); falls back to Poisson's if NB failed to converge but
# Poisson didn't; discards the term entirely (empty tibble, which flows
# harmlessly through each cell's existing filter()/mutate() chain) if
# NEITHER model converged. Every non-empty result is tagged with a
# `model_fit` column so the combined forest plot can show which model
# actually produced each rate ratio.
safe_tidy <- function(nb_fit, poisson_fit) {
  if (model_converged(nb_fit)) {
    broom.mixed::tidy(nb_fit, conf.int = TRUE, exponentiate = TRUE) %>%
      dplyr::mutate(model_fit = "NB")
  } else if (model_converged(poisson_fit)) {
    cat("  NB failed to converge - falling back to Poisson for this term.\n")
    broom.mixed::tidy(poisson_fit, conf.int = TRUE, exponentiate = TRUE) %>%
      dplyr::mutate(model_fit = "Poisson")
  } else {
    cat("  Both Poisson and NB failed to converge - rate ratio not reported for this term.\n")
    tibble::tibble()
  }
}

hads <- read.xlsx(paste0(data.path, "Baseline2022/hads.xlsx")) %>%
  dplyr::filter(!is.na(ParticipantId)) %>%
  dplyr::left_join(demographics, by = "ParticipantNo") %>%
  dplyr::filter(age > 17) %>%
  # Substract 1 from every value (scores are coded 1-4)
  dplyr::mutate(dplyr::across(FeelTense:CanEnjoyBookTV, ~ . - 1)) %>%
  # Reverse encoding
  dplyr::mutate(dplyr::across(
    c(FeelTense, FrightenedFeelingSomethingAwful, WorryingThoughts, FeelCheerful,
      FeelSlowedDown, LostInterestAppearance, FeelRestless, SuddenFeelingsPanic),
    ~ 3 - .
  )) %>%
  # Works out composite score
  dplyr::mutate(
    anxiety_hads = FeelTense + FrightenedFeelingSomethingAwful + WorryingThoughts +
      SitAtEase + FrightenedFeelingButterflies + FeelRestless + SuddenFeelingsPanic,
    depression_hads = EnjoyThings + CanLaugh + FeelCheerful + FeelSlowedDown +
      LostInterestAppearance + LookForward + CanEnjoyBookTV
  )

group_hads <- function(score) {
  cut(score, breaks = c(0, 7, 10, 21), labels = c("0-7", "8-10", "11-21"), include.lowest = TRUE)
}

hads_exposure <- hads %>%
  dplyr::transmute(
    ParticipantNo,
    anxiety_score_group = group_hads(anxiety_hads),
    depression_score_group = group_hads(depression_hads)
  )

event_counts_soft <- event_counts_soft %>% dplyr::left_join(hads_exposure, by = "ParticipantNo")
event_counts_hard <- event_counts_hard %>% dplyr::left_join(hads_exposure, by = "ParticipantNo")

## Introduction

Poisson/negative-binomial equivalent of the Cox models in `Primary
Analysis/`: We thi models the number
of flare events during follow-up (recurrent events) (see
`Events per individual.R` and `build_event_counts.R` for how those counts
and the endpoint definitions are constructed).

Six exposures are tested, as in thecorresponding `Primary Analysis` file
(HADS, PHQ, PSQI, Exercise, Fatigue, Life Events).

Every exposure is broken down into Full Cohort/Crohn's Disease/Ulcerative
Colitis-IBDU, each further split by patient-reported (soft) vs objective
(hard) flare (the same structure `Primary Analysis`).
Each of those cells fits an unadjusted model (exposure +
`(1 | SiteNo)`) and an adjusted one (+ `Sex + age_decade + Smoke + IMD +
FC`), as both Poisson and negative binomial,
written out explicitly per cell rather than looped. A combined forest plot across
all six exposures follows the individual sections.

Requires the `lme4` and `broom.mixed` packages.

Accumulates every model's tidied rate ratios as we go, for the combined
forest plot at the end.

```{r}
rate_ratios <- tibble::tibble()

# A model "failed to converge" means lme4's own post-fit check flagged it
# (fit@optinfo$conv$lme4$messages non-NULL) - NOT the same as a singular fit
# (boundary (singular) fit), which is a valid degenerate solution (a
# variance component at zero), not a convergence failure.
model_converged <- function(fit) {
  is.null(fit@optinfo$conv$lme4$messages)
}

aic_or_na <- function(fit) {
  if (model_converged(fit)) round(AIC(fit), 1) else "NA (failed to converge)"
}

# Swapped in for every broom.mixed::tidy(<nb model>, conf.int = TRUE,
# exponentiate = TRUE) call below. Prefers the NB rate ratio (this repo's
# usual choice); falls back to Poisson's if NB failed to converge but
# Poisson didn't; discards the term entirely (empty tibble, which flows
# harmlessly through each cell's existing filter()/mutate() chain) if
# NEITHER model converged. Every non-empty result is tagged with a
# `model_fit` column so the combined forest plot can show which model
# actually produced each rate ratio.
safe_tidy <- function(nb_fit, poisson_fit) {
  if (model_converged(nb_fit)) {
    broom.mixed::tidy(nb_fit, conf.int = TRUE, exponentiate = TRUE) %>%
      dplyr::mutate(model_fit = "NB")
  } else if (model_converged(poisson_fit)) {
    cat("  NB failed to converge - falling back to Poisson for this term.\n")
    broom.mixed::tidy(poisson_fit, conf.int = TRUE, exponentiate = TRUE) %>%
      dplyr::mutate(model_fit = "Poisson")
  } else {
    cat("  Both Poisson and NB failed to converge - rate ratio not reported for this term.\n")
    tibble::tibble()
  }
}
```

```{r}
  # Reverse encoding
  dplyr::mutate(dplyr::across(
    c(FeelTense, FrightenedFeelingSomethingAwful, WorryingThoughts, FeelCheerful,

    ~ 3 - .

    anxiety_hads = FeelTense + FrightenedFeelingSomethingAwful + WorryingThoughts +
      SitAtEase + FrightenedFeelingButterflies + FeelRestless + SuddenFeelingsPanic,

group_hads <- function(score) {
```

```{r}
    c(CantGetToSleep, WakeUpMiddleNight, UseBathroom, CannotBreath, CoughOrSnore,
      FeelTooCold, FeelTooWarm, BadDreams, HavePain, OtherTroubleSleeping,
      SleepQuality, SleepMedicines, StayingAwake, EnoughEnthusiasm),
    ~ . - 1
  )) %>%
  dplyr::rename(comp1 = SleepQuality) %>%
  dplyr::mutate(FallAsleepMns = dplyr::case_when(
    FallAsleepMns <= 14 ~ 0, FallAsleepMns <= 30 ~ 1, FallAsleepMns <= 60 ~ 2, TRUE ~ 3
  )) %>%
  dplyr::mutate(comp2 = dplyr::case_when(
    (FallAsleepMns + CantGetToSleep) %in% c(0) ~ 0,
    (FallAsleepMns + CantGetToSleep) %in% c(1, 2) ~ 1,
    (FallAsleepMns + CantGetToSleep) %in% c(3, 4) ~ 2,
    (FallAsleepMns + CantGetToSleep) %in% c(5, 6) ~ 3
  )) %>%
  tidyr::replace_na(list(SleepEachNightMns = 0)) %>%
  dplyr::mutate(
    TotalSleepMinutes = SleepEachNightHrs * 60 + SleepEachNightMns,
    comp3 = dplyr::case_when(
      TotalSleepMinutes < 300 ~ 3,
      TotalSleepMinutes >= 300 & TotalSleepMinutes <= 359 ~ 2,
      TotalSleepMinutes >= 360 & TotalSleepMinutes <= 419 ~ 1,
      TotalSleepMinutes >= 420 ~ 0
    )
  ) %>%
  # Correcting non-24h clock entries (verbatim from Primary Analysis/PSQI.qmd,
  # including its hardcoded per-participant exceptions/corrections below).
  dplyr::mutate(
    BedTimeHrs = dplyr::case_when(
      ParticipantNo %in% c(110415, 110463) ~ BedTimeHrs,
      BedTimeHrs == 7 ~ 19, BedTimeHrs == 8 ~ 20, BedTimeHrs == 9 ~ 21,
      BedTimeHrs == 10 ~ 22, BedTimeHrs == 11 ~ 23, BedTimeHrs == 12 ~ 00,
      BedTimeHrs == 13 ~ 1, BedTimeHrs == 0 ~ 00, BedTimeHrs == 1 ~ 01,
      BedTimeHrs == 2 ~ 02, BedTimeHrs == 3 ~ 03, BedTimeHrs == 4 ~ 04,
      TRUE ~ BedTimeHrs
    )
  ) %>%
  tidyr::replace_na(list(BedTimeMns = 0, WokenUpMns = 0)) %>%
  # Participant 170004: obvious typo (5h sleep from the reported times) - excluded.
  dplyr::filter(ParticipantNo != 170004) %>%
  # Participants 110351/120042: obvious typos in WokenUpHrs - corrected.
  dplyr::mutate(WokenUpHrs = dplyr::case_when(
    ParticipantNo == 110351 ~ 6, ParticipantNo == 120042 ~ 9, .default = WokenUpHrs
  )) %>%
  dplyr::mutate(
    BedTimeDT = lubridate::make_datetime(hour = BedTimeHrs, min = BedTimeMns),
    WokenUpDT = lubridate::make_datetime(day = 2, hour = WokenUpHrs, min = WokenUpMns)
  ) %>%
  dplyr::mutate(
    BedTimeDT = dplyr::case_when(
      BedTimeHrs >= 0 & BedTimeHrs <= 8 ~ BedTimeDT + lubridate::days(1),
      TRUE ~ BedTimeDT
    )
  ) %>%
  dplyr::mutate(TotalBedMinutes = lubridate::interval(BedTimeDT, WokenUpDT) / lubridate::minutes()) %>%
  dplyr::mutate(SleepEff = TotalSleepMinutes / TotalBedMinutes * 100) %>%
  dplyr::mutate(comp4 = dplyr::case_when(
    SleepEff < 65 ~ 3, SleepEff < 75 ~ 2, SleepEff < 85 ~ 1, SleepEff >= 85 ~ 0
  )) %>%
  dplyr::mutate(TotalTrouble = rowSums(dplyr::select(., WakeUpMiddleNight:OtherTroubleSleeping))) %>%
  dplyr::mutate(comp5 = dplyr::case_when(
    TotalTrouble == 0 ~ 0, TotalTrouble <= 9 ~ 1, TotalTrouble <= 18 ~ 2, TotalTrouble <= 27 ~ 3
  )) %>%
  dplyr::rename(comp6 = SleepMedicines) %>%
  dplyr::mutate(comp7 = dplyr::case_when(
    (StayingAwake + EnoughEnthusiasm) %in% c(0) ~ 0,
    (StayingAwake + EnoughEnthusiasm) %in% c(1, 2) ~ 1,
    (StayingAwake + EnoughEnthusiasm) %in% c(3, 4) ~ 2,
    (StayingAwake + EnoughEnthusiasm) %in% c(5, 6) ~ 3
  )) %>%
  dplyr::mutate(TotalScore = comp1 + comp2 + comp3 + comp4 + comp5 + comp6 + comp7) %>%
  # score > 5 is "poor sleep"
  dplyr::mutate(SleepDisturbance = factor(dplyr::if_else(TotalScore <= 5, "No", "Yes"), levels = c("No", "Yes")))
```

same structure the manuscript uses to report the Cox findings. Blue = 95%
CI excludes 1 (the recurrent-event analogue of a significant association).

```{r}
#| fig-width: 10

rate_ratios %>%
  # broom.mixed::tidy() names these estimate/conf.low/conf.high - rename to
  # match the rate_ratio/lower/upper used below.
  dplyr::rename(rate_ratio = estimate, lower = conf.low, upper = conf.high) %>%
  dplyr::filter(model == "Adjusted") %>%
  dplyr::mutate(
    # model_fit ("NB" or "Poisson") shown on every row - NB failed to
    # converge and Poisson was used instead for any row tagged "Poisson"
    # (see safe_tidy() in Setup); a term is absent entirely if neither
    # model converged.
    label = paste0(exposure, ": ", term, " [", model_fit, "]"),
    significant = lower > 1 | upper < 1,
    # Character "diagnosis" sorts alphabetically (Crohn's Disease, Full
    # Cohort, Ulcerative...) putting Full Cohort in the middle - force it
    # to the top instead.
    diagnosis = factor(diagnosis, levels = c("Full Cohort", "Crohn's Disease", "Ulcerative Colitis/IBDU"))
  ) %>%
  ggplot2::ggplot(ggplot2::aes(x = rate_ratio, y = label, colour = significant, shape = model_fit)) +
  ggplot2::geom_vline(xintercept = 1, linetype = "dashed", colour = "grey50") +
  ggplot2::geom_pointrange(ggplot2::aes(xmin = lower, xmax = upper)) +
  ggplot2::scale_x_log10() +
  ggplot2::scale_colour_manual(values = c(`TRUE` = "#0F8B8D", `FALSE` = "grey60"), guide = "none") +
  ggplot2::scale_shape_manual(values = c(NB = 16, Poisson = 17), name = "Model used") +
  ggplot2::facet_grid(diagnosis ~ outcome) +
  ggplot2::labs(x = "Adjusted rate ratio (95% CI, log scale)", y = NULL) +
  ggplot2::theme_minimal()
```
